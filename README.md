# Smart Cough Analyzer

AI-powered cough analysis system that predicts respiratory conditions using cough audio recordings.

---

# Frontend Setup

```bash
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# Backend Setup

```bash
cd backend
python app.py
```

Backend runs on:

```bash
http://127.0.0.1:5000
```

---

# Features

- Upload WAV cough audio
- AI prediction system
- Spectrogram visualization
- Waveform visualization
- Confidence score
- PDF report generation

---

# Tech Stack

## Frontend
- React

- Framer Motion

## Backend
- Flask
- TensorFlow Lite
